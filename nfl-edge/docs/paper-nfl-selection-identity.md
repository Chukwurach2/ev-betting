# Explicit NFL selection identity for paper settlement

The paper ledger can retain an NFL event's canonical home/away team codes while the observed spread selection uses the book's full team name. Previously, the outcome evaluator required selection text to equal a canonical event team key. Even with a final and exact-book contract evidence, these entries stayed unresolved as unsupported selections.

This change permits a retrospective, manually reviewed `selection_mapping` inside the exact observation/book contract evidence. It must contain a nonempty review ID, reviewed status, exact sport, game ID, observation ID and selection text, home/away side, matching canonical `team_key`, HTTPS source and a review timestamp between the quote and the evaluation time. Only NFL spread aliases use this path. The original observation remains unchanged. The evaluated result retains the mapping ID, canonical team key and source for audit.

There is no name parser, fuzzy match, shared alias dictionary or inferred home/away side. Missing or inconsistent evidence remains unsupported. Existing event/start mapping, final/period checks and exact-book rule requirements still apply. Totals retain exact Over/Under semantics, and NBA behavior is unchanged. The reviewer must inspect authoritative team identity and the original selection; filling in matching JSON fields alone is not source verification. Review is retrospective and does not establish pregame knowledge, an accepted offer or wager settlement.

Validation: 15 offline outcome assertion cases, including home/away orientation, losing/winning sides, wrong sport/event/observation/selection/side, blank selection, insecure source, stale-before-quote/future review and rule/final/period rejection. The complete current 956-record ledger (566 observations,404 earliest entries) was recomputed at the preserved report's original generation time with retained evidence. The complete report deep-equals the baseline: no prior outcome, unresolved reason or hypothetical return changed. No real selection mapping or new grade was added in this increment. Hosted CI explicitly runs the standard outcome, event-mapping and performance suites.

This focused PR stacks on PR44's exact-book guard. It does not merge, deploy, modify the private journal/frozen model, acquire prices or enable live execution. Source rules, full final/identity review and observation-specific mapping remain prerequisites before grading an NFL alias entry.
